# Account Management System Test Plan

This plan captures the behavior currently implemented by the COBOL account-management application. Unless a case says otherwise, start a fresh program run for each case; the account starts at `1000.00` and its in-memory balance resets when the program starts again. Cases performed in one run share the same balance. Compare balances numerically to two decimal places; record the exact terminal formatting observed, since the COBOL fields use an implied decimal point.

Cases marked as requiring a business decision describe input behavior that the source code does not define. Agree on the expected policy before treating those cases as pass/fail or translating them into Node.js tests.
